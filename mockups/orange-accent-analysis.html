Subtle orange threads through the design, in the color of the logo

01

The mismatch

The logo is a warm coral orange (#E87848), but every accent in the UI is indigo (#4f46e5). The eye is trained to read orange as the brand, so any indigo flourish quietly fights the logo.

03

Where orange goes (the rules)

Three simple rules keep the orange from becoming noise: small elements, moving state, and logo-adjacent marks. Everything else stays indigo / gray.

Active state

The thing you're doing right now should glow orange. Sidebar nav, current step, selected tab.

Progress & motion

Progress bars, spinners, focus rings — anywhere attention is on the move.

Marks & dots

Tiny "is this thing on?" indicators: connection dot, "current selection" chip, badge counts, the small book icon.

05

Implementation in 3 small steps

step 1

Add the accent palette to tailwind.config.js

// tailwind.config.js — inside theme.extend.colors
accent: {
  50:  '#fdf4ef', 100: '#fae6da', 200: '#f5cdb6', 300: '#eda988',
  400: '#e58e62', 500: '#e87848',  // logo orange
  600: '#d8633a', 700: '#b34e2c', 800: '#8c3d24', 900: '#5f2a1a', 950: '#3a1810',
},
step 2

Pick the swap targets (one file, one decision)

Don't rewrite everything. Use a single global search/replace per pattern in these 5 files:

File Find (indigo accent) Replace (orange accent)
shell.component.html bg-brand-50/30 text-brand-600/400 bg-accent-500/10 text-accent-300/400
shell.component.html text-brand-500 (theme icons) text-accent-400
config.component.ts getStepClass — current/done → accent-500 + ring-accent-500/40 + pulse halo
export.component.html bg-brand-500 (progress bar) bg-accent-500 + shadow glow
settings.component.html current-selection card orange-bordered, accent-tinted bg
all form inputs focus:ring-brand-500 focus:ring-accent-500
shell status dot status dot (green/red only) add tiny orange "ready" dot + green stays for live
step 3

What to leave alone

  • › Large primary CTAs (Save, Generate, Export full) — keep indigo. They need to feel structural, not decorative.
  • › Big gradient tiles like the generator header card (currently from-brand-500 to-brand-700) — swap the start stop to from-accent-500 if you want, but the dark-to-light gradient feels right in indigo too.
  • › The "Fill Random" purple button in config — it already uses a different color on purpose. Leave it.
  • › The favicon in public/favicon.svg — that's a system asset, not a UI element. (But you could ship a new orange book icon later if you want consistency.)
